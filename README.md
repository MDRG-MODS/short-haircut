A short boyish bob hairstyle modification for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)**.

---

## 🎮 Features

- **Stylish Bob Hairstyle:** Gives the robot companion a chic, short tomboy haircut.
- **RGB Hair Dye Remote:** Includes an in-game RGB controller to customize hair color on the fly.
- Compatible with MDRG version **v0.97.12** (Target: `0.97.11`).

---

## ⚙️ Mod Type

This is an **Internal Mod**, designed to be imported, enabled, and managed directly using MDRG's built-in in-game mod manager (available on PC, Mac, and Android). It does not require external modding tools or loaders such as LemonLoader.

Ready-to-use mod packages are available under the [**Releases**](https://github.com/MDRG-MODS/short-haircut/releases) tab.
