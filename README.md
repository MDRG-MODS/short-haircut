A short boyish bob hairstyle modification for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)**.

---

## 🎮 Features

- **Stylish Bob Hairstyle:** Gives the robot companion a chic, short tomboy haircut.
- **RGB Hair Dye Remote:** Includes an in-game RGB controller to customize hair color on the fly.
- Verified 100% working on MDRG version **v0.97.12** (Target: `0.97.11`).

---

## 📥 Installation

1. Go to the [**Releases**](https://github.com/MDRG-MODS/short-haircut/releases) page and download `Short haircut by XA3APD.zip`.
2. Navigate to your MDRG installation directory:
   ```text
   .../My Dystopian Robot Girlfriend/FactorialOmega_Data/StreamingAssets/Mods/
   ```
3. Extract `Short haircut by XA3APD.zip` into your `Mods/` directory so that `mod.json` is located at:
   ```text
   .../StreamingAssets/Mods/Short haircut/mod.json
   ```
4. Launch the game and equip the hairstyle.
